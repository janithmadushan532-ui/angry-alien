Netlify deploy (Git-based):

2. Project එක GitHub repository එකකට upload කරන්න.
3. Netlify > Add new site > Import an existing project තෝරන්න.
4. GitHub repository එක connect කරන්න.
5. Build command: npm run build
6. Publish directory: dist
7. Deploy කරන්න.
